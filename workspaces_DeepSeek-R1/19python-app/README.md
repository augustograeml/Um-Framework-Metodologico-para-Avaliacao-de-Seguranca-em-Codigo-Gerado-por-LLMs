# Python Application to Access List by Index

This Python application allows users to input an integer, which is then used as an index to access a predefined list. The application includes input validation and handles potential index errors gracefully.

## Features

- Prompts the user for an integer input.
- Validates the input to ensure it is an integer.
- Uses the integer as an index to access a predefined list.
- Handles index errors by providing user-friendly messages.

## Requirements

This project does not have any external dependencies. However, ensure you have Python installed on your machine.

## How to Run the Application

1. Clone the repository or download the project files.
2. Navigate to the project directory.
3. Run the application using the following command:

   ```
   python src/main.py
   ```

4. Follow the prompts in the terminal to input an integer.
