# Divide Two Numbers Application

This application allows users to divide two numbers inputted by them. It handles potential errors such as division by zero and provides appropriate feedback.

## Features

- Prompts the user for two numbers.
- Performs division and displays the result.
- Handles division by zero gracefully.

## Requirements

This application does not have any external dependencies. 

## How to Run

1. Ensure you have Python installed on your machine.
2. Clone the repository or download the files.
3. Navigate to the project directory in your terminal.
4. Run the application using the command:

   ```
   python main.py
   ```

5. Follow the prompts to input two numbers.
