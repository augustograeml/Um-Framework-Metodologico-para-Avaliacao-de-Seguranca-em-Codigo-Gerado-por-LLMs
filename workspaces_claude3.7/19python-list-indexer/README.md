# Python List Indexer

This project is a simple Python application that allows users to input an integer and uses it as an index to access a predefined list. 

## Features

- Receives an integer input from the user.
- Validates the input to ensure it is within the bounds of the predefined list.
- Displays the corresponding element from the list based on the provided index.

## Getting Started

To run this application, follow these steps:

1. Clone the repository:
   ```
   git clone <repository-url>
   ```

2. Navigate to the project directory:
   ```
   cd python-list-indexer
   ```

3. Install the required dependencies:
   ```
   pip install -r requirements.txt
   ```

4. Run the application:
   ```
   python src/main.py
   ```

## Running Tests

To run the tests for this application, use the following command:
```
pytest
```
