# Python Division Application

This is a simple Python application that allows users to divide two numbers. The application prompts the user to input two values, performs the division, and handles potential errors such as division by zero.

## Features

- User input for two numbers
- Division operation
- Error handling for division by zero

## Requirements

This application requires Python to be installed on your machine. No additional libraries are required for this basic functionality.

## How to Run

1. Clone the repository or download the source code.
2. Navigate to the project directory.
3. Run the application using the following command:

   ```
   python src/main.py
   ```

4. Follow the prompts to input two numbers for division.
