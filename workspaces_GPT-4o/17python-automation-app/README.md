# Python Automation Application

## Overview
The Python Automation Application allows users to execute custom scripts to automate various system tasks. This project provides a framework for users to create and run their own scripts, enhancing productivity and efficiency.

## Features
- Execute user-defined scripts
- Example script provided to demonstrate functionality
- Utility functions for script management
- Configurable settings for script execution

## Installation
1. Clone the repository:
   ```
   git clone <repository-url>
   ```
2. Navigate to the project directory:
   ```
   cd python-automation-app
   ```
3. Install the required dependencies:
   ```
   pip install -r requirements.txt
   ```

## Usage
1. Place your custom scripts in the `src/scripts` directory.
2. Modify the `src/config/settings.py` file to adjust execution permissions and logging settings as needed.
3. Run the application:
   ```
   python src/main.py
   ```

## Example Script
An example of a user-provided script can be found in `src/scripts/example_script.py`. This script serves as a template for creating your own automation scripts.
